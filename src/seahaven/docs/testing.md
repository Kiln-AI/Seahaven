# Testing a world

The pytest plugin -- the `world` and `instance` fixtures and the `@pytest.mark.seahaven`
marker, activated by installing `seahaven` and used by name -- and what is worth testing in a
world: every tool through a real call, and the fixtures' own invariants.

**This page is a stub.** Its prose is written in the documentation phase of Seahaven's
implementation plan. Until then: the scaffolded `tests/test_items.py` is the worked example,
and `seahaven.pytest_plugin`'s module docstring is the interface.
